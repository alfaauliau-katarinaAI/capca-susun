# Katarina Vision Lab v0.5 — official 2Captcha access

- One-tap **Masuk akun 2Captcha** launches `https://2captcha.com/auth/login` in the device's own browser.
- **Dashboard Worker** opens `https://2captcha.com/cabinet`.
- **Aplikasi 2Captcha Bot resmi** opens Google's official Play Store listing.
- All 2Captcha credentials, Client Key, sessions and payments remain outside Katarina. No WebView injection, hidden cookie access, auto-login or task automation.
- OCR laboratory still supports local ML Kit + optional Cloudflare (model inference not verified yet).
- 2Captcha is **not integrated as a paid-work API**, and income or continuous auto-solving is not promised.
- No new permissions added. No new scheduled workflows added. Build triggered only by Android source update.
